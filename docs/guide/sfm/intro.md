# SFM 学习指南

Source Filmmaker（简称 SFM）是 Valve 基于 Source 引擎推出的影视动画制作工具。这份文档由社区贡献者共同编写，从下载安装讲到打光、Rig 与 VMT，也会记录一些踩坑经验。

## 这份文档怎么读

- **第一次使用 SFM**：按左侧「🚀 入门」的顺序阅读，先完成下载、汉化与资产导入。
- **想做一张海报**：直接跟着「📓 海报实例」走一遍完整流程。
- **遇到报错**：先查「💩 BUG」分类，再带着截图和日志去社区提问。
- **想改材质**：从「💀 混沌」里的 VMT 系列开始。

左侧侧边栏用于切换章节；进入文章后，可以用右侧的「指南大纲」快速跳到指定小节。
