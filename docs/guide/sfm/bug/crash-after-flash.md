# 屏闪后崩溃

## 现象

打开 Source Filmmaker 时，软件可能短暂弹窗或不弹窗，随后闪屏并自动关闭。社区里通常把这种现象叫作「闪屏后崩溃」。

## 可能原因

运行库损坏或显卡驱动过旧。

## 解决方法

1. **修复运行库**：安装或修复常用的 Windows 运行库合集。我使用的是 [系统总裁运行库](https://www.sysceo.com/Software-softwarei-id-257.html)。
2. **更新显卡驱动**：可以使用驱动人生、驱动精灵，或我使用的 [驱动总裁](https://www.sysceo.com/dc)。
3. **重启电脑**，然后再次启动 SFM。

## 仍未解决

带上系统版本、显卡型号和报错截图，到社区提问，方便他人帮你定位。
