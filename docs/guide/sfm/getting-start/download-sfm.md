# 下载 Source Filmmaker

## 获取 Source Filmmaker

目前获取 Source Filmmaker 的官方渠道只有一个：[Steam 商店](https://store.steampowered.com/app/1840/Source_Filmmaker/)。请不要从其他来源下载。

![Steam 商店中的 Source Filmmaker 页面](https://ae01.alicdn.com/kf/HTB1GjCdT9zqK1RjSZFHq6z3CpXac.jpg)

::: tip 提示
SFM 是免费软件。如果你本地没有安装，它不会一直留在 Steam 库中；需要时在商店页面重新获取即可。
:::

## 启动

在 Steam 中打开「库 → 软件」，找到 Source Filmmaker，点击「启动」。

如果你需要更高的渲染分辨率或离线启动，可以继续阅读 [调整分辨率](/guide/sfm/trivia/resolutions) 和 [离线启动](/guide/sfm/trivia/nosteam)。
