# 汉化补丁

::: danger 汉化补丁作者建议
不要使用汉化补丁。
:::

::: warning 注意
使用汉化补丁会导致 **窗口布局全部消失（灰屏）** 和 **创意工坊订阅文件找不到** 等问题。
遇到这些情况，请查看 [汉化补丁常见问题](/guide/sfm/bug/hanization-patch-bug)。
:::

## 获取补丁

汉化补丁由贴吧用户 **黄金史莱米** 制作，原帖发布于 [百度贴吧](http://tieba.baidu.com/p/4347071082)。

你也可以通过[本站镜像](https://cdn.learnder.org/share/sfm汉化补丁v0.3.zip)获取补丁文件。

## 安装补丁

1. 关闭 Source Filmmaker。
2. 解压补丁压缩包。
3. 将补丁文件覆盖到 Source Filmmaker 主目录。
4. 重新启动 SFM。

![汉化补丁安装步骤示意](https://pic.imgdb.cn/item/5ccb0f513a213b04178dab37.jpg)

::: tip 提示
安装前建议备份 `game` 目录，方便出问题时快速恢复。
:::
