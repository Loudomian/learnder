- **第一次接触 3D**：从 [Blender 引言](/guide/blender/intro) 开始，了解 Blender 能做什么、适合谁学。
- **想用 SFM 做海报**：先读 [SFM 引言](/guide/sfm/intro)，再跟着 [海报实例](/guide/sfm/instance/monika-poster/intro) 完整做一遍。
- **想完善这份文档**：阅读 [文档编写指南](/contributing)，按模板提交你的第一篇教程。
